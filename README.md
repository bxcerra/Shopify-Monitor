<h1 align="center">Shopify Monitor</h1>

## Description
```
  A sample code to monitor and detect new products added to Shopify stores
```

## About config.json
```
  -> site-url : URL of the Shopify website you want to monitor
  -> webhook-url : URL of the Discord webhook you want to use to receive alerts when a new product is detected
  -> delay : The time you want the monitor to wait between each request (in seconds)
```
